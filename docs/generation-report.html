Qué demuestra este ejercicio

Valor para un cliente: el agente no se limitó a escribir código. Leyó un repositorio de reglas, diseñó la API desde OpenAPI, generó el proyecto, detectó errores reales en CI, corrigió dependencias y tipos, reparó la configuración de Cucumber, elevó la cobertura desde un 12% hasta cumplir el 80% y publicó únicamente cuando los gates acordados pasaron.

El resultado es trazable: cada iteración quedó registrada en commits y GitHub Actions. Esto permite usar el agente como acelerador de delivery sin renunciar a controles técnicos objetivos.

- Tests unitarios, controladores y Cucumber.
- JaCoCo con mínimo 80% de cobertura de líneas.
- GitHub Actions para validar compilación y mvn verify.

API completa

El contrato OpenAPI define dos dominios públicos: Workouts y Shoes. A continuación se listan los 10 endpoints expuestos.

POST/api/v1/workouts

Crear entrenamiento

Body: WorkoutCreateRequest. Obligatorios: workoutDate, workoutType, completed, source. Puede incluir segmentos, laps y track points.

201 Workout creado · 400 petición inválida.

GET/api/v1/workouts

Buscar entrenamientos

Filtros: workoutType, workoutDate, workoutDateFrom, workoutDateTo, completed, shoeId, source, además de paginación Spring.

200 Página de WorkoutSummaryResponse.

GET/api/v1/workouts/{id}

Obtener entrenamiento

Path: id int64.

200 WorkoutResponse · 404 no encontrado.

PATCH/api/v1/workouts/{id}

Modificar parcialmente entrenamiento

Body: WorkoutPatchRequest. Soporta presencia explícita y valores nulos para PATCH mediante JsonNullable.

200 actualizado · 400 inválido · 404 no encontrado.

DELETE/api/v1/workouts/{id}

Eliminar entrenamiento

Path: id int64.

204 eliminado · 404 no encontrado.

POST/api/v1/shoes

Crear zapatilla

Body: RunningShoeCreateRequest.

201 creada · 400 petición inválida.

GET/api/v1/shoes

Buscar zapatillas

Listado paginado mediante parámetros de paginación Spring.

200 RunningShoePageResponse.

GET/api/v1/shoes/{id}

Obtener zapatilla

Path: id int64.

200 RunningShoeResponse · 404 no encontrada.

PATCH/api/v1/shoes/{id}

Modificar parcialmente zapatilla

Body: RunningShoePatchRequest.

200 actualizada · 404 no encontrada.

DELETE/api/v1/shoes/{id}

Eliminar zapatilla

Impide eliminar una zapatilla referenciada por entrenamientos.

204 eliminada · 404 no encontrada · 409 zapatilla en uso.
